- 結果：2026-10-24に同一質問を各モデルで1回実行した。応答時間は API リクエスト部分の経過時間（秒）で、ネットワークやサービス側の混雑も含まれる。

  | モデル | 質問 | 入力トークン | 出力トークン | 応答時間 |

  | `gemini-3.5-flash-lite` | LoRAとは何ですか？ | 7 | 614 | 3.097秒 |
  | `gemini-3.6-flash` | LoRAとは何ですか？ | 7 | 644 | 10.887秒 |
  | `gemini-3.5-flash-lite` | AIE2026の「lecNN-start タグ」とは何ですか？ | 23 | 426 | 3.340秒 |
  | `gemini-3.6-flash` | AIE2026の「lecNN-start タグ」とは何ですか？ | 23 | 476 | 10.452秒 |

  実行例：

  ```bash

  AIE_MODEL=gemini-3.6-flash uv run python -m app.ask "LoRAとは何ですか？"
  ```

- 気づき・疑問：今回の1回ずつの測定では、`gemini-3.5-flash-lite` の応答が短時間だった。ただし試行回数が少なく、ネットワークやサービスの混雑も影響するため、モデル固有の速度差とは断定できない。講座固有の質問では、`gemini-3.6-flash` は開始タグから演習を始められると説明した一方、`gemini-3.5-flash-lite` はタグを教材内の目印と誤解した。
